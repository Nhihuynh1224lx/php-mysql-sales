## Lỗi đã tìm thấy và đã sửa

### 1. 5 lỗi cú pháp PHP (fatal — trang không chạy được)

→ Sửa lại thành `header('Location: /admin/products/');`
(Lưu ý: `edit.php:1235` cũng có `href="/admin/products/"` nhưng đó là thẻ `<a>` Hủy hợp lệ, giữ nguyên.)

### 2. 39 đường dẫn include cũ ở 13 file (fatal)
Các file vẫn `require_once '/var/www/src/includes/header.php'` trong khi partial đã dời
sang `src/includes/admin/`. Trang chết với "Failed opening required".
Các file: `public/suppliers/{index,create,edit}.php`, `public/customers/{index,create,edit}.php`,
`public/orders/{index,create,edit,show}.php`, `public/admin/employees/{index,create,edit}.php`
→ Đổi hết sang `/var/www/src/includes/admin/{header,navbar,footer}.php`.

### 3. Link nội bộ 404 sau khi dời thư mục
- `src/includes/admin/navbar.php`: `/categories/`, `/shippers/`, `/employees/` → thêm tiền tố `/admin/`

  mục "Đơn hàng" trỏ nhầm về `/` → sửa thành `/orders/`
- `public/admin/employees/index.php`: `/employees/create.php`, `/employees/edit.php`,
  `action="/employees/delete.php"`, `src="/employees/upload/..."` → thêm `/admin/`
- `public/admin/employees/create.php`, `edit.php`: nút Hủy, ảnh, `Location:` → `/admin/employees/`
- `public/admin/employees/delete.php`: 3 chỗ `Location: /employees/` → `/admin/employees/`
- `public/admin/products/index.php:130`: `/products/edit.php?id=` → `/admin/products/edit.php?id=`

## Kiểm chứng

- `php -l` toàn bộ `public/` + `src/`: sạch, 0 lỗi.
- Quét 31 route: tất cả 200/302, 0 warning/notice/fatal.
- Audit toàn bộ link nội bộ: **hết 404 trong khu admin**; chỉ còn `/shop/*` (xem bên dưới).
- Probe headless (Edge) trên `/orders/create.php` — 11/11 PASS:
  thêm dòng 1→2, xoá dòng 2→1, đơn giá 49.900.000 đ, thành tiền = 49.900.000 × 3 = 149.700.000,
  tổng tiền = tổng các dòng.
- Ảnh nhân viên `/admin/employees/upload/emp-708df8ffc8bfcc85.jpg` → 200, hiển thị đúng.
- Xem ảnh chụp: trang nhân viên + tạo đơn hàng render đúng, navbar/footer đã hiện
  "Nhân viên giao hàng".

## Còn tồn — cần người dùng quyết định

1. **Dashboard trang chủ đã mất.** `public/index.php` hiện là placeholder 362 byte
   ("Ứng dụng PHP đang hoạt động."), trong khi navbar "Trang chủ" trỏ về `/`.
   Bản dashboard thật (880 dòng, thẻ thống kê + sản phẩm mới + sắp hết hàng) còn trong
   `../php-mysql-sales - Copy/public/index.php` — khôi phục được nhưng phải sửa lại
   include + link y như các lỗi ở trên.
2. **Storefront đã mất hoàn toàn.** `public/shop/` và `public/assets/css/storefront.css`,
   `public/assets/js/storefront.js` không còn trên đĩa và **chưa từng được commit**
   (git chỉ có 4 file `src/includes/storefront/*.php`) → không thể khôi phục từ git.
   `src/includes/storefront/*.php` hiện là code chết, vẫn trỏ tới `/shop/*` (404).
3. `public/admin/products/upload-test.php` là trang debug còn sót, không được link ở đâu.
4. `README.md` vẫn rỗng (đã ghi nhận từ trước).

## Ghi chú kỹ thuật

- Chạy lint không nên dùng `xargs -n1 php -l` vì nó **dừng ngay** ở file lỗi đầu tiên,
  che mất các file lỗi phía sau. Dùng `find ... -exec php -l {} \;` để quét hết.
- `curl -o /dev/null` trên Git Bash trả exit 23 (lỗi ghi) dù HTTP code vẫn đúng — bỏ qua exit code.
